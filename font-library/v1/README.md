# SillyTavern 公共字体库 v1

生成日期：2026-07-13

本目录包含 30 个可复用字体家族。全部来自 Google Fonts 官方仓库，
每个字体目录都保存原始 `OFL.txt`、`METADATA.pb`、来源记录和 WOFF2 文件。
日系字体用于视觉风格补充，不保证覆盖全部简体中文字形；中文正文优先使用 `zh-cn` 分类。

## 使用方式

- 可直接引用本目录的固定提交版本 `library.css`。
- 也可只复制某个 `@font-face`，并在主题中设置明确的中文回退链。
- 正式主题必须固定到具体提交哈希，不能直接依赖会变化的 `main`。
- 每个字体的许可证都在对应目录；二次分发时必须保留许可证。
