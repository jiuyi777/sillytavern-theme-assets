# SillyTavern 公共字体库 v2

生成日期：2026-07-13

本版本包含 18 个经过来源与再分发许可核对的字体家族；其中 4 个是 v2 既有条目，本次从用户截图请求新增 14 个。
每个字体目录都保存 WOFF2、许可文本与 `source.json`；`previews/` 保存包含中文、西文、数字和标点的字样预览。

## 使用规则

- 正式主题一次只加载用户选定的字体，不要一次加载整库。
- 主题必须引用固定提交哈希 Raw URL，不能长期引用 `main`。
- 西文字体的预览明确标注中文由系统字体回退，不能把回退效果误认成该字体自带中文。
- 带 OFL 保留字体名的源字体在转换后采用 `ST Theme ... Web` 内部家族名；未改动的官方 WOFF2 保留原名。
