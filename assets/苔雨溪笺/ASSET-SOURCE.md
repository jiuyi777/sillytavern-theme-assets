# Asset source

- `guofeng-rain-garden-v5.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20. It is a people-free Jiangnan rain-garden ink painting with a pale central reading area and contains no text, logo, seal, or watermark.
- `toolbar-emblems-v6.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20, then converted locally from a flat `#ff00ff` chroma-key background to transparent PNG.
- The 3x3 atlas contains nine consistent opaque paper-jade medallions with abstract cloud, bamboo, plum, mountain, ripple, moon, lotus, feather, and knot motifs. It contains no text, logo, watermark, or literal copies of the original UI functions.
- Each medallion covers the centered original SillyTavern icon while loaded. The original icon remains underneath as an automatic loading-failure fallback; the image layer never intercepts pointer input and the real trigger keeps the full toolbar-cell hit area.
- The superseded user-provided pond image and v4 six-object sprite remain in project-local history. The rejected literal v5 toolbar atlas was moved to `assets/history/v5/` and is not included in this final publish directory.
- The P2 composition reference and user screenshots are not included in this publish directory.
