# Asset source

- `pond-stone-foliage.png` was supplied by the user in the current theme task and explicitly requested as the replacement scene.
- It is not claimed as original artwork by `@jiuyi0204`.
- The theme uses it only as a non-interactive background with a plain-color fallback.
- The P2 layout reference is not included in this publish directory.
- `small-objects-sprite-v4.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20, then converted locally from a flat `#ff00ff` chroma-key background to transparent PNG.
- The six-cell atlas contains a moss sprig, blank oxblood seal, ink droplet, gold bud charm, paper fan, and rain-beaded pond stone. It contains no text, logo, watermark, or user-provided reference image.
- The sprite is decorative only; original SillyTavern icons, controls, labels, events, and pointer targets remain the functional fallback.
