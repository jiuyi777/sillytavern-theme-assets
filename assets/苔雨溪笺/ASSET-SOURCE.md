# Asset source

- `moon-pavilion-sides-v8.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20. The user's second reference image was used only for the broad pavilion-framed celestial-landscape composition and mood. The final is an original, people-free mineral-pigment and ink-wash landscape in pale celadon, muted turquoise, moss, ivory, antique gold, ink green, and restrained dark walnut.
- The v8 scene is composed for a centered 56%-wide opaque paper chat column: the far-left 22% contains carved pavilion woodwork, bamboo and near mountains; the far-right 22% contains a pale moon, layered peaks, bridge, pine and flowering branches. The center stays pale and low-detail because it will be covered by the paper chat. It contains no person, text, logo, seal, watermark, AI badge, or copied reference-image interface.
- `toolbar-emblems-v6.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20, then converted locally from a flat `#ff00ff` chroma-key background to transparent PNG.
- The 3x3 atlas contains nine consistent opaque paper-jade medallions with abstract cloud, bamboo, plum, mountain, ripple, moon, lotus, feather, and knot motifs. It contains no text, logo, watermark, or literal copies of the original UI functions.
- Each medallion covers the centered original SillyTavern icon while loaded. The original icon remains underneath as an automatic loading-failure fallback; the image layer never intercepts pointer input and the real trigger keeps the full toolbar-cell hit area.
- The superseded user-provided pond image and v4 six-object sprite remain in project-local history. The rejected literal v5 toolbar atlas and v5 Jiangnan rain-garden image are in `assets/history/v5/`; the v7 pavilion landscape is in `assets/history/v7/`. None is included in this final publish directory.
- The P2 composition reference and user screenshots are not included in this publish directory.
