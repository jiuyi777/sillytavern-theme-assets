# Asset source

- `pavilion-shanshui-sides-v7.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20. The user's second reference image was used only for the broad pavilion-framed celestial-landscape composition and mood. The final is an original, people-free mineral-pigment and ink-wash landscape in muted celadon, moss, ivory, antique gold, charcoal, and dark walnut.
- The v7 scene is composed for a centered 56%-wide opaque paper chat column: carved pavilion edges, mountains, pine, bamboo, cloud ribbons, water, and moon remain readable in the outer 22% gutters, while the center stays calm and low-detail. It contains no person, text, logo, seal, watermark, AI badge, or copied reference-image interface.
- `toolbar-emblems-v6.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20, then converted locally from a flat `#ff00ff` chroma-key background to transparent PNG.
- The 3x3 atlas contains nine consistent opaque paper-jade medallions with abstract cloud, bamboo, plum, mountain, ripple, moon, lotus, feather, and knot motifs. It contains no text, logo, watermark, or literal copies of the original UI functions.
- Each medallion covers the centered original SillyTavern icon while loaded. The original icon remains underneath as an automatic loading-failure fallback; the image layer never intercepts pointer input and the real trigger keeps the full toolbar-cell hit area.
- The superseded user-provided pond image and v4 six-object sprite remain in project-local history. The rejected literal v5 toolbar atlas and the v5 Jiangnan rain-garden image were moved to `assets/history/v5/` and are not included in this final publish directory.
- The P2 composition reference and user screenshots are not included in this publish directory.
