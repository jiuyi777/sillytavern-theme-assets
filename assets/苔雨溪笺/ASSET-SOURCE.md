# Asset source

- `guofeng-rain-garden-v5.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20. It is a people-free Jiangnan rain-garden ink painting with a pale central reading area and contains no text, logo, seal, or watermark.
- `toolbar-icons-v5.png` was generated for this theme with OpenAI's built-in image generation tool on 2026-07-20, then converted locally from a flat `#ff00ff` chroma-key background to transparent PNG.
- The 3x3 icon atlas contains bamboo tuning rods, a lantern, brush and inkstone, an antique book, jade pendant, landscape scroll, interlocking blocks, a half-mask, and an identity plaque. It contains no text, logo, or watermark.
- The toolbar atlas supplies the primary themed visual while original SillyTavern icons remain as a small semantic and loading-failure fallback. Decorative layers never intercept pointer input.
- The superseded user-provided pond image and v4 six-object sprite were moved to the project-local `assets/history/v4/` directory and are not included in this final publish directory.
- The P2 composition reference and user screenshots are not included in this publish directory.
